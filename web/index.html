PAIRED CELL ESTIMATOR
δm,i=MAEm,i,U−MAEm,i,SΔ^DiD=1K∑i=1K(δFM,i−δbase,i)
U = unseen · S = seen · i matches task, label budget, seed and trial budget.
PAIRED BOOTSTRAP
CI95=[Q0.025(D¯*),Q0.975(D¯*)]p^boot=1+∑b=1B1(|D¯0*|≥|Δ^DiD|)B+1
The interval resamples K matched cells; the p-value uses centered null replicates.
Positive Δ̂DiD means the foundation arm has a larger unseen-minus-seen error gap in the matched comparison.
Pairing rule
Compare like with like
Pairs must match task, label budget, seed and tuning-trial budget. The primary p-value is the centered two-sided bootstrap test; sign-flip inference is a separately reported sensitivity check.

Neq is the estimated baseline label count needed to match the foundation model at the selected target N, minus that target N. It is model- and cohort-specific.

Compute–error Pareto frontier
Awaiting observed data
PNo comparable compute records
Observed cells need unseen MAE and positive GPU time before the frontier can be drawn.
Lower-left points are preferred: fewer recorded GPU-hours and lower unseen MAE. Synthetic runs are excluded.

          

          
Log-linear learning model
MAEm,c(n)=am,cln(n)+bm,c+εn
For each model m and cohort c, ordinary least squares fits MAE against ln(label budget) using shared observed budgets.
Equivalent baseline labels
Neq(N0)=exp(MAE^FM,c(N0)−bbase,cabase,c)−N0
abase,c < 0decreasing baseline curve
This inverts the fitted baseline curve to estimate its labels required minus the target N0; a negative value means the baseline reaches that error earlier.
Compute–error Pareto dominance
j≺i⇔hj≤hi,ej≤eihj<hi∨ej<ei
Both compute hours h and unseen MAE e are minimized. A point stays on the frontier if no other model dominates it.
